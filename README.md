# Наскрізний проєкт з дисципліни «Вебтехнології та вебдизайн»
Автор: Хорошилова Анна, група 5-ІПБ
Тема: «Хвиля» — вебкаталог україномовних подкастів із текстовими розшифровками випусків і пошуком за змістом
Стек: React + PHP + MySQL

## Про проєкт
«Хвиля» — вебзастосунок, у якому гість слухає подкасти, читає розшифровку кожного випуску й шукає фрагменти за словами з тексту; зареєстрований слухач зберігає випуски у вибране та коментує їх, а адміністратор наповнює каталог подкастів, випусків і категорій.
